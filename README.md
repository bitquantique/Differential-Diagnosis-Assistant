# Differential Diagnosis Assistant

An AI-assisted clinical decision-support system that analyzes textual patient records to identify symptoms, medical history, and clinical findings, and suggests multiple potential diagnoses based on the available evidence.

## Features

- **Patient Record Analysis:** Extracts relevant clinical information from patient records.
- **Differential Diagnosis Generation:** Suggests multiple plausible diagnoses based on the available information.
- **Supporting Evidence:** Explains which symptoms and findings support each diagnosis.
- **Contradicting Evidence:** Highlights findings that conflict with or weaken each potential diagnosis.
- **Symptom Coverage:** Identifies which symptoms are explained by a diagnosis and which remain unexplained.
- **Confidence Score:** Provides an estimated confidence score for each potential diagnosis.
- **Structured Output:** Presents diagnostic possibilities and their supporting analysis in a concise, organized format.

## Objective

The project aims to assist healthcare professionals in exploring potential diagnoses, evaluating clinical evidence, and considering alternative explanations for a patient's symptoms.

Rather than selecting a single definitive diagnosis, the system presents multiple possibilities with transparent reasoning to support clinical decision-making.

## Disclaimer

*This tool is an educational project and is not intended for clinical use, medical diagnosis, or patient treatment.*
